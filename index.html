DS5 Connect

DualSense(PS5) 컨트롤러를 macOS에서 키보드+마우스로. 자이로 조준, 터치패드 마우스, 자유로운 버튼 매핑까지 완전 무료.

macOS 완전 무료 USB / 블루투스
⬇ 다운로드 (macOS)
최신 버전 · .dmg

스크린샷

기능

  • 자이로 조준컨트롤러를 기울이면 마우스 커서로 변환
  • 터치패드 마우스트랙패드처럼 손가락으로 드래그
  • 자유 버튼 매핑버튼 클릭 → 키 클릭으로 즉시 저장
  • 세컨키(모디파이어)버튼 하나로 매핑 두 배로 확장
  • 연결 상태 실시간 감지블루투스 끊김/재연결 자동 반영
  • 한국어 / English재시작 없이 언어 전환

설치 방법

  1. DS5 Connect.dmg를 다운로드해 연 다음, DS5 Connect.app을 Applications 폴더로 드래그하세요.
  2. 처음 실행하면 "확인되지 않은 개발자" 경고가 뜰 수 있습니다 — 개인 개발자가 배포하는 무료 앱이라 애플 정식 서명을 아직 받지 않아서 그렇습니다, 악성코드 검사와는 무관합니다.
    • Finder에서 앱 아이콘을 control+클릭(우클릭) → 열기 → 대화상자에서 열기
    • 안 되면: 시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 → "차단됨" 옆 그래도 열기 → 암호 입력
  3. 한 번 허용하면 이후에는 경고 없이 정상 실행됩니다.
macOS에서는 첫 실행 시 시스템 설정 → 개인정보 보호 및 보안에서 손쉬운 사용(Accessibility), 입력 모니터링(Input Monitoring) 권한도 허용해야 키/마우스 입력이 실제로 전달됩니다.
